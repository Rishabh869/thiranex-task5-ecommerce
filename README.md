# ShopSphere — Thiranex Task 5

A responsive front-end e-commerce product catalog built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive product catalog
- Search, category filters, and sorting
- Shopping cart with quantity controls and localStorage persistence
- Client-side hash routing for Home, Shop, About, and Cart
- Empty states, toast messages, and demo newsletter form
- Lazy-loaded product images and responsive layout

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy on GitHub Pages
1. Create a **public** GitHub repository named `thiranex-task5-ecommerce`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages URL to appear on the same screen. Open it and test Home, Shop, About, and Cart.

## Notes
This is a front-end demo. It does not have a backend, user accounts, inventory management, or real payment processing. Product images are loaded from Unsplash URLs and require internet access.
